# strategy — Anchor the loop

**Purpose**
Write a short product anchor that ideate, grill, and plan must read. This is not the memory bank and not `AGENTS.md`.

**Trigger**
"Write the strategy", "update STRATEGY.md", or a planning session with no product anchor.

**Do not use for**
- Session continuity → `memory-bank-protocol`
- A hard-to-reverse technical decision → ADR via `docs-protocol`
- Domain glossary → `grill-with-docs` (`CONTEXT.md`)

## Steps
1. Read the repo README, recent docs, and `docs/solutions/` before you ask.
2. Interview. Push back on slogans and feature lists. Ask one decision at a time.
3. Write `STRATEGY.md` at the active project root with only these sections: Purpose. Positioning. Users. Boundaries. Metrics (3 to 5). Tracks (2 to 4).
4. Update in place. Do not create `STRATEGY-v2.md`.
5. Do not replace `memory-bank/projectbrief.md`. Point to it if both exist.
